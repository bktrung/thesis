# Vietnamese NeoBERT via SALT

Adapting **NeoBERT** (250M-param English encoder, SOTA benchmark performer) to Vietnamese using **SALT** (Semantic Aware Linear Transfer), a novel cross-lingual transfer method. Instead of training from scratch, we transfer ViDeBERTa's embeddings to NeoBERT's space, then continue pretraining on Vietnamese text.

**Current status**: Prototype on Google Colab. Phase 0 in progress.

## The SALT Method

**SALT** (Semantic Aware Linear Transfer) adapts models across languages by transferring embeddings:

### Key Idea
1. **Anchor mining**: Find semantically equivalent token pairs (e.g., Vietnamese "xin" ↔ English "please")
2. **FastText projection**: Use Vietnamese FastText embeddings to find nearest anchors
3. **Local least-squares**: For each non-shared token, solve a local linear transform using nearby anchors
4. **Norm calibration**: Scale embeddings to match target model's distribution
5. **Continual pretraining**: Fine-tune on target-language data

### Advantages
- **Unsupervised**: No parallel corpus required
- **Parameter-efficient**: Reuses NeoBERT's 28-layer encoder
- **Fast**: SALT init ≈ 2–3 hours vs 250M params × 2.1T tokens ≈ $100K training cost
- **Modular**: Init artifact can be reused by multiple training runs

## Pipeline Overview

### Stage 1: SALT Initialization (01_init_embeddings_salt3.ipynb)
- Prune ViDeBERTa tokenizer (128K → 32K)
- Mine anchor pairs (3-tier: numbers + verified forms + translations)
- Apply SALT projection per token
- Save reusable init artifact

**Time**: ~2–3 hours | **Output**: `init/{INIT_NAME}/model/`

### Stage 2: Continual Pre-Training (02_train_cpt_run.ipynb)
- Load SALT-initialized model
- Stream & tokenize CulturaX-vi (Vietnamese, up to 3M docs)
- MLM training with custom NeoMLMTrainer
- Save final model & metrics

**Time**: ~5–10 hours (3M docs) | **Output**: `runs/{RUN_NAME}/final_model/`

### Stage 3: Downstream Evaluation (03_evaluate_downstream_salt3.ipynb)
GLUE-type-aligned Vietnamese suite (10 tasks), one shared protocol for every model:
- **Tasks**: PPPL; sentiment (UIT-VSFC), emotion (UIT-VSMEC), toxicity (UIT-ViCTSD);
  NLI translated (XNLI-vi) + native (ViANLI); semantic similarity (STS, Spearman);
  QNLI (derived from UIT-ViQuAD2.0); POS (UD-VTB); MRC (UIT-ViQuAD2.0, full data)
- **Models (4)**: SALT3 vs PhoBERT-v2, ViDeBERTa-base (donor), XLM-R base
- **Protocol**: hybrid HP grid (small tasks) / tuned LR (big), true early stopping,
  5 seeds, VnCoreNLP word-segmentation for PhoBERT/ViDeBERTa, mean±std + bootstrap 95% CI
  + paired-bootstrap significance vs SALT3, NeoBERT task-type coverage table
- **Covers NeoBERT GLUE types**; CoLA has no Vietnamese equivalent (documented gap),
  full MTEB embedding eval is future work (cite VN-MTEB)

**Output**: per-task tables + `eval/<name>/eval_results_summary.json`

## Troubleshooting

### Issue: ModuleNotFoundError: No module named 'salt3_common'
**Solution**: Ensure `code/salt3_common.py` is in the same directory as notebooks, or add to sys.path:
```python
import sys
sys.path.insert(0, '/path/to/code')
```

### Issue: eval_loss >> log(vocab_size) (≈10.4)
**Symptom**: Model loss is much higher than random baseline.  
**Diagnosis**: Run `diagnose_model_health(model, tokenizer)` to check embedding norms and encoder weights.  
**Cause**: Likely embedding or decoder weights not loaded correctly.  
**Fix**: Verify `model.safetensors` integrity; re-save init artifact if needed.

### Issue: CUDA out of memory
**Solution**:
- Reduce batch size: `BATCH_SIZE = 16`
- Reduce gradient_accum: `GRADIENT_ACCUM = 8`
- Use bf16 precision: `bf16=True` in TrainingArguments
- Or use smaller dataset: `NUM_EXAMPLES = 400_000`

### Issue: Google Translate API rate-limited
**Solution**:
- Increase delay in anchor mining: `time.sleep(0.5)` between requests
- Use only MarianMT (no Google): Set `USE_GOOGLE = False` in notebook
- Cache translations to file for resumability
